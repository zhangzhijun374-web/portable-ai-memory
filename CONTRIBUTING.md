# Contributing

Thank you for helping improve Portable AI Memory.

## Ways to contribute

- Improve the memory extraction and update workflow.
- Add templates for new user or project types.
- Improve source provenance and conflict handling.
- Add privacy safeguards and validation checks.
- Test compatibility with Agent Skills hosts.
- Improve documentation and translations.

## Before opening an issue or pull request

- Do not include real chat exports, personal memory files, private documents, or credentials.
- Use synthetic examples.
- Describe the expected behavior and the observed behavior.
- Include the AI host and version when reporting compatibility issues.
- Keep changes focused and explain why they improve the workflow.

## Pull request checklist

- [ ] No real personal data or secrets are included.
- [ ] Examples use synthetic information.
- [ ] The core skill remains platform-neutral where possible.
- [ ] Platform-specific behavior is labeled and linked to official documentation.
- [ ] Templates distinguish facts, plans, historical items, and uncertainty.
- [ ] Documentation has been updated.
- [ ] Validation scripts pass.

## Design philosophy

Portable AI Memory should be useful without forcing users into a particular AI vendor, cloud service, database, or proprietary memory format. Prefer readable files, explicit provenance, user control, and simple workflows.
